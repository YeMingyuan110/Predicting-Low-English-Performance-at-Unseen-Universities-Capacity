# Public release selection

Included files were selected to document the analysis methods and support the main manuscript findings: cohort/measurement checks, model performance, nested probability calibration, group fairness, capacity allocation, human-review triage, and global feature interpretation.

Excluded material includes raw student records, analysis frames, row-level OOF predictions, individual SHAP attributions, model checkpoints, temporary Word lock files, logs, Python bytecode, incomplete-run folders, manuscript drafts, and duplicate intermediate tables. The `资料/` directory duplicates parts of the working code/results and is not separately copied. Only the nested-selected probability workflow is retained for downstream fairness, allocation, and review outputs; obsolete or duplicate calibration routes are excluded from the release tables.
