# Supplementary Code and Aggregate Results

This folder contains the analysis code, model configuration, recorded software versions, and selected aggregate outputs for the current cross-university English education study.

## Contents

- `code/`: preprocessing, university-held-out modeling, probability calibration, fairness auditing, capacity allocation, review triage, threshold-sensitivity, and risk-comparison scripts.
- `code/config/experiment_config.json`: primary analysis settings. The source-workbook path is a relative placeholder and must be set to the authorized local dataset.
- `environment/`: recorded training software versions and a pinned environment reference.
- `results/tables/`: selected aggregate tables reported in the manuscript or needed to verify its main results.
- `results/figures/`: selected manuscript-quality calibration, group-audit, and global interpretation figures.
- `docs/`: data access, workflow, and file-selection notes.
- `provenance/SHA256SUMS.csv`: checksums for files in this release.

## Data protection and exclusions

No source workbook, student-level analysis frame, row-level out-of-fold predictions, individual SHAP attributions, trained checkpoints, temporary files, run logs, manuscript drafts, or incomplete-run artifacts are included. The analysis code requires the source workbook and generates intermediate student-level files locally. These files are excluded by `code/.gitignore`; do not commit them to a public repository. Obtain and use the source data only through the access conditions stated in the manuscript and the data provider's terms.

The public tables contain aggregate results only. The fairness table's gender labels are translated to English in this release; the underlying analysis is unchanged.

## Reproduction outline

1. Use Python 3.11 and install the package versions recorded in `environment/recorded_software_versions.txt`. GPU execution requires a compatible CUDA-enabled PyTorch installation; the recorded run used CUDA 12.6.
2. Place the authorized workbook at `code/data/source_workbook.xlsx`, or edit `data_workbook` in `code/config/experiment_config.json` to its local path. Set `data_sheet` to the workbook's actual sheet name.
3. From the `code/` directory, run `python run_pipeline.py --start 1 --stop 6 --feature-set T0 --risk-quantile 0.25`.
4. The full pipeline includes nested university-held-out training and may require substantial compute. For a partial run or an existing verified training output, use the module-specific command-line options documented in each script.
5. `code/07_threshold_sensitivity/threshold_sensitivity.py` summarizes results only after the corresponding q=0.15 and q=0.35 runs have been generated. Those additional runs are not bundled in this release.

The statistical comparison in `code/08_risk_comparison/` uses calibrated OOF predictions generated by the pipeline. It reproduces the university-cluster bootstrap comparison and calibration ECE table/figure when those local, student-level prediction artifacts are available.

## Analysis settings

The primary configuration specifies five outer university folds, three random seeds (42, 3407, 2027), a 25th-percentile low-performance threshold, a 10% primary support capacity, and 2,000 bootstrap resamples for group and allocation analyses. The paired risk-model comparison uses 5,000 university-cluster bootstrap resamples with seed 20261113. Hyperparameter selection and calibration selection are performed within training universities; held-out universities are reserved for evaluation.

The release contains selected aggregate results, not all intermediate outputs. Historical run logs and machine manifests are omitted because they contain local file paths and checkpoint references.
